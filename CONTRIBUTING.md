# Contributing

1. Branch from `main`; use Conventional Commit messages (`feat:`, `fix:`, `chore:`).
2. Run `just lint` and `just check` before opening a pull request. Both also run in CI.
3. This repository is public: no secrets, account IDs, role ARNs, internal hostnames or internal repository names in
   code, examples, comments or commit messages.

To add an action, follow "Adding an action" in [AGENTS.md](AGENTS.md).
